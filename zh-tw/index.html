用手機掃條碼， 自動輸入到電腦。

把手機相機對準條碼，內容就會輸入到電腦上目前開著的視窗，就像 USB 條碼掃描器一樣。每次掃描後還能自動按 Tab、Enter 或任何快速鍵。

npx barbarcode

電腦需要 Node.js 22 以上版本。手機不用裝 App，也不用註冊帳號。

使用方式

  1. 在電腦上執行

    在終端機執行 npx barbarcode，畫面上會出現 QR Code。

  2. 用手機掃描 QR Code

    掃描器會在手機瀏覽器中開啟，不需要安裝 App。

  3. 對準條碼

    每個條碼都會輸入到游標所在的位置：試算表、表單、POS 收銀畫面都可以。

自訂每次掃描後的按鍵

把按鍵設定檔存在 barbarcode.toml（執行 npx barbarcode init 可以產生範例），再用 npx barbarcode -s price_check 啟動。掃描時也能直接在手機上切換設定檔。

設定檔格式實際輸入
inventory {barcode}{enter} 4006381333931 Enter
price_check {f4}{barcode}{enter} F4 4006381333931 Enter
data_entry SKU:{barcode}{tab}Quantity: SKU:4006381333931 Tab Quantity:
search {cmd+k}{delay:150}{barcode}{enter} ⌘ K 等待 150 毫秒 4006381333931 Enter

另外也支援 {tab}、{esc}、方向鍵、{f1} 到 {f24}，以及 {ctrl+s} 這類快速鍵。條碼內容一律以純文字輸入，所以條碼本身絕對不會觸發快速鍵。

任何網路都能用

手機瀏覽器只允許在安全（HTTPS）的網頁使用相機，所以 barbarcode 會提供一個安全網址，讓手機連到你的電腦。預設方式在任何網路都能用；其他方式則讓連線只經過你自己選擇的服務。

指令連線方式需要準備
npx barbarcode 透過 barbarcode 中繼伺服器，任何網路都能連 不需要
--via cloudflare 由你自己執行的臨時 Cloudflare 通道 cloudflared，不需要帳號
--via tailscale 透過你的 tailnet，只有你自己的裝置能連線 已開啟 HTTPS 的 Tailscale

掃描內容全程端對端加密。金鑰只存在 QR Code 裡，所以中繼伺服器和通道都無法讀取你的掃描內容，也無法在你的電腦上輸入任何東西。

支援 macOS、Windows 和 Linux

macOS
第一次使用時，到「系統設定」的「隱私權與安全性」>「輔助使用」允許你的終端機 App。
Windows
不需要額外設定。
Linux
請安裝 xdotool（X11）或 wtype（Wayland）。
